# COMSOL → Lumerical 能力迁移审计

审计日期：2026-10-29，工具统一更新于 2026-10-30。能力按“可直接共享的数值工具”“新增求解器适配”“仍需原求解器的专属能力”区分。
保留原 COMSOL 执行路径能够保有已有功能，但不能据此声称该功能已经迁移为 Lumerical 原生实现。
以下区分已经实现的迁移接口和仍需验证的物理结论。首轮 12 个原生器件测试已完成全部源列，
其中 11 个通过预设诊断；粗网格 add-drop 环保留了数值检查未通过的结果。

## 本轮完整器件链路的验收条件

目标链路为：参数化几何 → 原生端口/模式 → 每个源列的实际求解 → 完整复数矩阵 → 数据导出 → 电路消费 → 候选目标计算。
至少保留双端直波导和四端耦合器的源身份、全部复数元素与原生模型。
在同一模型层级下比较网格和相位；若换成有限高度三维结构，应另列为不同模型。
不能把求解完成、互易性好或导出文件存在单独当作器件性能验收。

直波导可用低反射、接近单位的传播功率和实际参考面之间的相位作为控制。
耦合器没有预设 50:50 性能；其全矩阵用于检查所有源列、能量账目和参数响应。
环的粗谱不能用于声称 Q、线宽或谐振插值精度。
辐射、吸收、漏掉的导模和数值误差必须保持区别；未测量时只报告未分类余量。

首轮测试包含直波导和耦合器的 mesh 3/5 控制、交叉、MMI、Y 分支、all-pass 环、
add-drop 环、PN 环光学外形、三维直波导与色散直波导。所有声明的 2/3/4 个端口均分别激励，
未由对称性或互易性补列。源间模场检查比较未缩放的 E/H、范数、相位和实际采样坐标；
入射功率按原生方向修正符号检查，输出矩阵不作归一化修复。

粗 add-drop 环的最大奇异值为 `1.05596930486669`，超过本轮 `1.05` 的幅度数值余量，
因此 `diagnostic_passed=false`，不能作为成功优化观察。其他环即使落在余量内，也不能据此
声明无源性或高 Q 精度。原电路验证仍默认使用 `1e-6` 的最大奇异值余量；导出时可显式指定
`--passivity-tolerance`，范围 `[0, 0.05]`，仅记录为电路输入的数值接受设置，原矩阵保持不变。

这套迁移保留了已有仿真入口并增加 Lumerical 光学器件闭环。它没有把 `.mph` 二进制、
COMSOL 研究/网格、PN/Poisson、多物理场与伴随执行器转换为 Lumerical 原生等价实现。
实际使用命令与输入见 [完整器件工作流](../../references/lumerical-device-workflow.md)。
